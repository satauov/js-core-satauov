3. Closures in My Code (Замыкания)
Замыкание (closure) возникает, когда функция сохраняет доступ к переменным из своей лексической области видимости даже после того, как внешняя функция завершила выполнение.
В функции counter() переменная count объявлена внутри, а возвращаемые методы (inc, dec, value) имеют к ней постоянный доступ. Это позволяет управлять переменной count, при этом она остается полностью защищенной от прямого изменения извне.
В функции memoize(fn) замыкание используется для сохранения кэша (объект Map) между вызовами. Возвращаемая функция обращается к этому кэшу и проверяет наличие сохраненного результата перед вызовом оригинальной функции fn.
